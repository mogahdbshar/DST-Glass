# DST Glass Product Scope
## Core
- Adaptive glass renderer for Android generations.
- Arabic-first RTL application experience.
- Glass presets and editable widget design state.
- Widget catalog with clock, system, daily and weather foundations.
- Multiple widget size classes.
- Local design persistence.
- Manual GitHub Actions builds only.
## Principles
- No unnecessary Android permissions.
- No paid service dependency.
- Native effects where supported, graceful fallback otherwise.
- Widget renderer remains separate from the full app renderer.
- Product identity is DST Glass; DSTWR is the parent brand.
